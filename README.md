# ClauseGuard AI — Autonomous Contract Redlining Engine

ClauseGuard AI is an autonomous enterprise contract redlining engine powered by **LangGraph**, **Groq (Llama / Qwen)**, **Hugging Face (`BAAI/bge-small-en-v1.5`)**, **Supabase PostgreSQL (`pgvector` + `AsyncPostgresSaver`)**, **Server-Sent Events (SSE)**, and a **Next.js 14 monochrome editorial interface**.

## Local Development Quickstart

### 1. Prerequisites
- Python 3.11+
- Node.js 18+ (with `pnpm`)
- Groq API Key
- Supabase Project (or runs in resilient in-memory mode for offline dev)

### 2. Backend Setup
```bash
cd backend

# Create virtualenv & install dependencies
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt

# Configure environment variables in backend/.env:
# GROQ_API_KEY=gsk_...
# SUPABASE_DB_URL=postgresql://postgres:[PASSWORD]@[HOST]:5432/postgres
# FRONTEND_ORIGIN=http://localhost:3000

# Run FastAPI server
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend Setup
```bash
cd frontend

# Install dependencies
pnpm install

# Configure environment variables in frontend/.env.local:
# NEXT_PUBLIC_API_URL=http://localhost:8000

# Run Next.js App Router
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Deployment Guide

### A. Supabase PostgreSQL Configuration
1. Create a project at [supabase.com](https://supabase.com).
2. Go to **Database** -> **Extensions** and ensure `vector` is enabled.
3. ClauseGuard AI automatically runs table migrations on startup:
   - `playbook_parents`: Stores parent chunks (~1200 chars) with section headers and child count.
   - `clauseguard_playbook_leaves`: Stores leaf embeddings (~320 chars) generated by `BAAI/bge-small-en-v1.5`.
   - `checkpoints` / `checkpoint_blobs`: Managed automatically by `AsyncPostgresSaver`.
4. Copy your Supabase URI from **Project Settings** -> **Database** -> **Connection string** (URI mode):
   `postgresql://postgres.[REF]:[PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres?pgbouncer=true`

### B. Deploying Backend to Render or Railway
#### Deploying to Render
1. Create a new **Web Service** pointing to your repository.
2. Set **Root Directory** to `backend`.
3. Set **Runtime** to `Python 3` or `Docker` (using provided `backend/Dockerfile`).
4. Set Environment Variables:
   - `GROQ_API_KEY`: Your Groq API key
   - `SUPABASE_DB_URL`: Your Supabase connection string
   - `FRONTEND_ORIGIN`: Your deployed Vercel domain (e.g., `https://clauseguard.vercel.app`)
5. Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT` (auto-configured in `render.yaml` & `Procfile`).

#### Deploying to Railway
1. Deploy from GitHub repo selecting the `/backend` folder.
2. Railway detects `backend/Dockerfile` or `Procfile` automatically.
3. Add environment variables `GROQ_API_KEY`, `SUPABASE_DB_URL`, `FRONTEND_ORIGIN`.

### C. Deploying Frontend to Vercel
1. Import repository in [vercel.com](https://vercel.com).
2. Set **Root Directory** to `frontend`.
3. Framework preset: **Next.js**.
4. Set Environment Variable:
   - `NEXT_PUBLIC_API_URL`: Your deployed FastAPI backend URL (e.g., `https://clauseguard-backend.onrender.com`).
5. Click **Deploy**. Vercel will build and host the application with edge CDN routing.
